# GG Radar — رادار أخبار الإيسبورتس

لوحة أخبار إيسبورتس حية، تُصنَّف تلقائياً حسب اللعبة والفريق والمنطقة ونوع الخبر، مع تمييز خاص للمشهد العربي.

## البنية
- `index.html` — الواجهة الأمامية (بدون أي مفتاح API فيها).
- `api/scan.js` — دالة سيرفر (Vercel Serverless Function) تتصل بـ Gemini API وتحمل المفتاح بأمان.
- `lib/categories.js` — تعريف الأقسام الستة وبرومبت التصنيف.

## قبل النشر
لازم تضيف متغيّر بيئة واحد في إعدادات المشروع على Vercel:

```
GEMINI_API_KEY = <مفتاحك من Google AI Studio>
```

احصل على مفتاح مجاني من: https://aistudio.google.com/apikey

## التشغيل محلياً (اختياري)
```
npm install
vercel dev
```

## ملاحظة
الأداة تعتمد على بحث الويب اللحظي (Grounding with Google Search) من Gemini، فجودة النتائج مرتبطة بجودة البحث نفسه. راجع المصدر دائماً قبل النشر.
